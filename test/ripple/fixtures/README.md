# Ripple reference fixtures

Generated by `scripts/export_ripple_reference.py` using the official
`ricursiveAI/Ripple-65B-Preview` Python implementation at revision
`e27e171792f303d74c048184e8259ba663cfa0d5` (Apache-2.0).
The generator checks both upstream Python source hashes before importing them.
`reference.json` records those hashes and the PyTorch version.

`model.safetensors` contains random synthetic Float32 parameters, **not**
production Ripple weights. The five-layer model has 8 hidden features, 4 query
heads of dimension 4, 2 KV heads, a 3-token local window and both local/global
layers. Norms and value-residual coefficients are nontrivial. A 23-token prompt
exercises both CUDA split-K and GEMM attention paths.

`tokenizer.json` is a tiny complete byte alphabet with one BPE merge, the
upstream splitting pipeline, and overlapping added tokens. The chat template
is copied from the pinned upstream release. `tokenizer_cases.json` also
records exact cases from the full official tokenizer; run those with
`LIFEAI_RIPPLE_TOKENIZER_DIR` pointing to the pinned official metadata.

`chat_cases.json` is generated by Hugging Face `apply_chat_template`, including
tool schemas, consecutive tool responses, Unicode, reasoning history and
`clear_thinking`. Python dependencies: CPU PyTorch, `transformers==4.57.6`,
`tokenizers`, `safetensors`, and `jinja2`.

The upstream license is retained in `LICENSE.upstream`.
